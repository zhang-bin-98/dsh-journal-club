# 自由拼图

产品行为细化，对应 [产品设计 §4.5](产品设计.md#45-幻灯片分页-slidesmd确认点-3渲染前确认)。用户决定位置与尺寸，系统提供可撤销的排版建议。没有固定画布比例或图片数量上限；实际资源不足时报告导出错误并保留草稿，不以固定图数拒绝操作。

## 页面与入口

- JC tab 内与「概览」「图源核对」并列的「自由拼图」入口；按会话记住项目/页面/拼图，选择已有图组或新建。没有 slides.md 或 jc.md 也能单独拼图。没有 figures.json 时只从 groups.json 的 members 恢复规范路径 figures/<id>.png，标签使用成员 ID；缺失成员显示已保存组合图、具体缺图提示并禁用保存，不自动生成 figures.json。
- 左侧窄栏显示拼图缩略图与名称，鼠标在列表上滚轮直接前后切换，不必点击；也支持点击、上下键及 Home/End。首尾不循环，连续小滚动累积并短暂节流，画布/素材区的滚动不切换拼图。当前项高亮且自动保持在列表可见区；缩略图展示已保存版本，新拼图显示占位，另标未保存与图源变化状态。有 slides.md 时按正文图片首次引用顺序显示拼图，重复引用只列一次；文稿不再引用、清单移除或 PNG 已删除的旧图不显示，旧草稿也不恢复它们。不删除磁盘文件。本次新建、尚未引用的拼图暂留当前会话末尾；无 slides.md 时按清单顺序。保存和改布局不改变文稿引用顺序。顶栏保留当前拼图、保存、加入对话与放大编辑；新建、建议排版、撤销/重做与栏显示收进「更多」。画布占主要空间，右栏分「素材 / 属性」两个标签，默认素材；导出范围、查看全部图片、成员移除与居中放在属性。选中或加入图片不自动切换标签。右栏可收起，窄容器保留左侧导航并将素材/属性放到画布下方；放大使用同一个编辑组件，保留草稿与素材浏览位置。
- 素材按 Figure 分组，显示完整等比缩略图和 Figure/Panel 来源，支持搜索。点击缩略图仅打开大图，独立「＋」按钮才加入画布；已加入的卡片保留原位置，标记「已加入 · 定位」，点击选中并定位画布对应图片。大图支持适应窗口和原图尺寸查看，关闭后回到触发卡片并保留列表滚动位置；大图中的键盘操作不传递到画布。
- 素材来自当前项目已经裁切的 Panel，复用已有 PNG 与文件读取缓存，仅在进入可见区域附近时读取缩略图，不新增缩略图服务或文件。加载中/失败保持卡片尺寸；失败可打开大图重试，不影响其他素材。可跨 Figure 添加任意数量；同一 Panel 在一个图组中保留唯一成员身份。素材不可读时展示原因，不用占位图冒充成功导出。

## 操作

- 拖动图片移动，四角等比缩放，方向键微调，Shift 加大步长。点击空白或 Esc 取消选择，Delete/Backspace 移出选中图片；输入框正常接收文字与快捷键。删除仅移出图组，不删除图源。
- 图片可移至当前编辑区之外，包括负坐标，松手后编辑区按需扩展；不会因超出旧范围而裁掉图片。重叠提示但不阻断。被遮挡的图片可从成员列表选中并用方向键移动。选中不改变导出顺序，按成员顺序绘制，不增加图层面板。
- 编辑区与导出范围分开：不要求设置画布宽高。默认「适应编辑区」自动按当前所有图片外缘加操作余量取景，拖动/缩放过程中固定视图坐标，结束后自适应；键盘调整、图片变化和窗口大小变化也跟随，不必手动点「查看全部图片」。切回适应模式时清除旧滚动偏移；手动 150%/200%/300% 放大仍保留滚动查看。「查看全部图片」作为回到适应模式的快捷入口。白底、石板灰细实线与微阴影标出导出外缘；外围使用冷灰编辑区，蓝色实线与控制点只标示选中的图片，左侧选中缩略图使用蓝边浅蓝底，输出尺寸随图片排列确定；960×540 只作空白编辑区与初始排版的参考。
- 新增图片按等比缩小后在画布中部错位放置，不重排已有图片。「建议排版」使用现有分区评分规则适配任意数量，只修改草稿，可撤销；水平/垂直居中将选中图片对齐当前图片群的外接矩形中心。没有模型自动重排或新增 LLM 接口，对话建议仍由宿主 agent 提供。 agent 首次拼图尽量沿用原 Figure 的左右/上下关系、行列分组、相对大小与阅读顺序，参考原始页图和 Panel 框，通过 geometry 明确布局；可收紧未选 Panel 留下的空隙。用户指令与已有手动布局优先；可读性或叙事确有需要时才调整并简要说明。这是提示词约定，不改变页面「建议排版」算法。
- 一次拖动/缩放结束记录一次撤销；Pointer cancel 或拖动中 Esc 撤销当前手势。内存保留最近 60 步，不写盘。切换图组保留各自草稿；切换工作台页面保留草稿；关闭整个 JC tab 或切换项目时，写入期间阻止离开，未保存时提示。未保存草稿不持久化，应用退出或插件卸载前仍需保存。

## 加入对话

- 选中拼图后点「加入对话」，通过宿主会话绑定的 `inputActions.captureInsertion/insertText` 插入图组 ID、组合 PNG 与 groups.json 的原生 `@"路径"` 文本引用，并留出修改意见位置；不发送消息、不替换输入框、不新增页面或上下文文件。引用本身不附带文件内容，文本明确固定原 ID、output 路径并禁止无意新建；agent 按引用读取后调用原有 `compose_panels`。
- 已保存且图源未过期时直接引用；新建、未保存或已知图源过期的拼图先复用现有保存逻辑，成功后引用。保存失败不加入旧图，仍保留草稿。空图、缺失素材或已知外部布局冲突时禁用。
- 保存前捕获输入版本，在原选择区末尾插入，不删除被选文字。期间用户编辑输入框或输入框暂不可写，宿主拒绝插入并提示重试；已成功保存的图不用再次保存。离开项目导致组件卸载时不补插引用。放大编辑中成功加入后收起，用户在左侧补充意见并自行发送。
- AI 修改 groups.json、slides.md 或组合 PNG 后，复用宿主文件通知自动加载已保存图组的新布局与缩略图，保留当前选中项和列表顺序。若图组有未保存的手动调整，则保留草稿、撤销历史与旧并发版本，沿用「重新加载布局（放弃当前草稿）」入口，不自动覆盖。保存或拖动期间收到的通知延后处理。

## 保存与文件

- 手动保存或「刷新图源」后的自动保存生成 `groups/<id>.png` 并更新 `groups.json`；重开已有图组恢复保存的图片位置与尺寸。UI 保存与 AI 调用工具均在清单中原位更新已有图组，只有新建图组追加到末尾。修改布局、尺寸或成员均保留原 ID 和原 asset 文件路径；只有用户明确新建/另存时才分配新身份。工具默认更新，未登记的 output 会报错，明确新建需 create:true 且不能覆盖已有文件。素材相同不自动合并。路径稳定，已有 slides.md 引用继续有效；新建图组仍需在 slides.md 引用，页面不自动修改叙事内容。
- 前后端共用几何验证、等比 contain 与像素取整。UI 与工具均先等比适配图片，再按所有图片的实际外缘取外接矩形，去除外围空白并平移到原点，保留相对位置、内部间隔和原图全部内容；不做原图像素内容裁切。UI 与 compose_panels 默认均输出外接矩形的 2 倍像素（向上取整；工具可用 scale 改），这不增加原始图源细节。拼图是 PPT 中的图片素材，不是整页幻灯片。Panel 重裁改变比例后在原包围框内等比适配，不改变其他图片位置。
- host 保存复用 `compose_panels` 核心，不新增第六个工具。保存检查载入时的清单摘要和所用图片内容摘要；保存中输入变化也报冲突。失败保留草稿，不自动覆盖外部修改。已有拼图清单发生外部修改时，提供「重新加载布局（放弃当前草稿）」读取其最新版本；普通图源刷新不会解除布局冲突。没有自动合并或强制覆盖按钮。
- 用户在现有图源核对页手动改框，由原有 `update_figures` → `crop` 路径更新 Panel PNG。返回拼图后点击「刷新图源」：更新素材尺寸、内容摘要与预览，保留仍在列表中的图组成员、坐标、包围框及撤销历史。读取本身不推进布局并发版本。缺失素材保留成员并提示，禁止保存；刷新失败保留草稿。比例变化在原框内等比适配，不重排。读取成功后自动复用保存逻辑，用最新素材与当前排版调用 `compose_panels` 重建当前组合图，成功才推进保存版本。布局冲突、素材缺失或写入失败时保留草稿并明确报错；当前图已被移除时不重新创建或自动保存其他图。其他受影响拼图标记待保存，不自动批量渲染，不新增界面、工具或级联任务。
- 组合 PNG 和清单通过现有原子文件写入机制更新，清单写入失败时恢复原 PNG；不是跨文件事务。编辑期间不逐帧写文件。
- 图组变更使 slides 的 groups digest 确认失效；已有 PPTX 不随 PNG 变化自动更新，需要重新渲染。

## 范围

只处理科研图片组合；不增加文字、旋转、图片拉伸、二次裁切、复杂图层或独立状态库。图片排列、图数、是否重叠由用户决定；图像是否适合汇报由人工检查，不用固定阈值替代判断。

实现与验证证据见 [自由拼图验收](../verification/free-composition-20261031.md)。
