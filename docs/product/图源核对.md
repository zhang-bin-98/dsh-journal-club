# 图源核对细化设计（v1）

> 隶属 [产品设计](产品设计.md) 4.3 步骤的交互细化。参考 SmartJC `docs/ui/图源核对.md` 的完整规格，按 dsh「聊天卡片 + 右侧栏 + 文件即真相」形态裁剪。

## 1. 流程位置与入口

- 前置：论文分析完成（全文解析 + 自动切分已产出候选框）。
- agent 完成分析后，在聊天流发出**图源卡片**（进度摘要 + 只读缩略图一览 +「打开核对工作台」/「确认图源」按钮）并停在等待状态；右侧栏 JC tab 切入核对工作台模式，步骤条第 2 步显示「等待核对」。不自动推进。
- 主论文与补充材料（如有）共用一次核对与一次整体确认，分组标识文件角色与页码。

## 2. 界面分工：右侧栏为工作台，聊天卡片为轻量入口

框编辑是长时间、精细、需要稳定画布的工作，放固定的右侧栏工作台；聊天卡片会被后续消息推挤且画布受限，只承载流程时刻与入口。对话联动不受影响——agent 修改 figures.json 后工作台自动刷新并高亮变更框（文件即真相）。

| | 聊天·图源卡片（轻） | 右侧栏·JC 工作台（重） |
|---|---|---|
| 定位 | 流程时刻 + 入口 | 核对主工作区，从 figures.json 实时驱动 |
| 内容 | 进度摘要（N Figure · M Panel · 疑点 K）、只读缩略图一览、「打开核对工作台」按钮、「确认图源」快捷按钮 | Figure 连续列表与全部框操作（见 §3–§5）、单图放大编辑、底部整体确认 |
| 生命周期 | 随聊天流逝 | 核对期间常驻；agent 对话修改后自动刷新并高亮变更框 |

「确认图源」在卡片与工作台双入口：无需手动调整的用户看一眼摘要直接在卡片确认，零跳转。

## 3. 工作台：Figure 连续核对列表

卡片主体为 Figure 顺序列表（含补充材料图，不按论文图号强制排序），每个 Figure 一块：

```text
┌─ Figure 3 · p.8 · 主论文 ── [已查看] [⚠️ 疑点 1] ──────────┐
│  ┌──────────────────────────────┐   ┌────────────┐      │
│  │  ┌──A──┐ ┌──B──┐             │   │ 当前选中     │      │
│  │  │     │ │     │  ┌─C┐ ⚠️    │   │ Panel 裁切   │      │
│  │  └─────┘ └─────┘  └──┘       │   │ 预览(严格按   │      │
│  │   （页面渲染 + 框叠加）        │   │ 选区等比）   │      │
│  └──────────────────────────────┘   └────────────┘      │
│  Panels: [A] [B] [C(⚠️)] [＋ 添加 Panel]                  │
│  ▸ 图注全文（默认折叠，Panel 片段高亮）                     │
│  操作: [采纳本图] [排除本图] [重新识别] [放大编辑] [恢复自动] │
└──────────────────────────────────────────────────────────┘
```

- 列表在右侧栏面板内连续滚动（同 dsh Files tab 模式），不受聊天流推挤；「放大编辑」在面板内弹出单 Figure 大图画布，应对密集 Panel 与小标签。
- **框叠加**：Panel 框以彩色边框 + 标签角标叠加在页面渲染图上；自动切分标疑点的框（重叠、疑似串入邻图、无标签、边缘穿切密集内容）显示 ⚠️ 角标，悬停显示理由。
- **裁切预览**：选中框的预览严格按选区裁切、等比显示，不露选区外内容——所见即最终裁切结果。
- **图注**：折叠展示完整图注；选中 Panel 时高亮其对应片段（多对多，如 "b–c" 同一片段高亮 b、c）；公共说明只标适用的 Panel，不无差别复制。

## 4. 单 Figure 框操作集

| 操作 | 交互 | 说明 |
|---|---|---|
| 选中 | 点框或点标签 chip | 同步高亮裁切预览与图注片段 |
| 移动框 | 拖动框体 | 仅动当前框，不牵连其他框 |
| 调整大小 | 四角手柄拖拽 | 简化自原版八手柄；方向键微调为可选实现 |
| 删除 Panel | 选中后 Delete / 按钮确认 | 移除该 Panel 身份及关联，不动其他框 |
| 添加 Panel | 「＋ 添加 Panel」进入框选模式，拖出框后原位填标签 | 允许空标签，不按位置猜 A/B/C |
| 改标签 | 点标签角标原位编辑 | 标签修改保留旧图注关联并标「关联待复核」 |
| 排除本图 | 按钮，需确认 | 弃图语义：不用于汇报，身份与图注保留，覆盖校验按用户主动弃图处理 |
| 采纳本图 | 按钮 | 标记该 Figure 核对完成（导航状态，非逐图审核门槛） |

操作即时写入 `figures.json`（草稿态，见 §7），无独立保存按钮；单 Figure 级回退用「恢复自动结果」（进入草稿对照，可放弃）。

**科学规则继承**：不抹白、不擦除、不重绘科研像素制造分隔；共享图例允许框适度重叠（重叠不报错，疑似串入邻图主数据才提示）；矩形难以独立保留必要标注（坐标/图例/比例尺/统计）时保留整图并标疑点，不强行产出残缺子图。

## 5. 添加 Figure、重识别与对话修正

**添加 Figure（漏检兜底）**：右侧栏/卡片提供「漏了一张图？」入口 → 选择来源文件与页码 → 页面缩略图上拖出整图范围 → 填图号（可空）→ 创建新 Figure 并自动补做 Panel 与图注关联，失败保留人工框并给局部重试。**v1 不做跨页图块追加**：跨页 Figure 自动按主块或整页处理并标疑点，用户可调框，不拼接多页（SmartJC 的跨页图块/图号归属转移不移植）。

**重新识别（单 Figure）**：`detect_figures` 工具可作用于指定 Figure，返回候选框；卡片以「自动候选 vs 当前框」对照展示，应用即写入草稿（diff 可见）。未应用不落盘。对话场景下 agent 判断后直接应用并展示变化即可。

**对话修正（与 SmartJC 的分歧点）**：SmartJC 规定图源步骤 AI 严格只读、禁止自然语言改框。dsh 形态下 agent 是用户信任的操作主体（与其编辑代码文件同等地位），对话修正如「Figure 4B 应该包含下面那排」由 **agent 直接编辑 figures.json 草稿**，编辑 diff 在聊天流天然可见——这就是监督机制，不自建候选确认门。skill 层面的行为约定（软约束，非硬门）：改动与用户已手动调整的框冲突时先说明再动；大范围操作（整篇重识别、全部重排标签）先讲计划。误操作恢复走对话让 agent 改回或从文件历史恢复，不建 Undo 树。

## 6. 确认模型

- 沿用 SmartJC「连续浏览 + 一次整体确认」：浏览状态（未查看/已查看/已调整/有疑点/已排除）只是导航信息，**不设逐 Figure 勾选审核**。
- 卡片尾部与右侧栏均有主按钮「**确认图源，生成大纲**」。
- 点击时若有未查看 Figure 或未处理疑点，**提示但不阻断**（「还有 2 个 Figure 未查看、1 个疑点未处理，确认将按当前状态继续」）——尊重用户主动省略。
- 确认动作：figures.json 定稿（revision 绑定当前切分版本）→ 按框从 PDF **重新裁切**落盘（不用预览压缩图）→ 触发 outline.md 生成 → 进入确认点 2。

## 7. 数据与版本

- `figures.json` 全程是唯一真相：草稿态（`status: draft`）接受卡片操作与 agent 修正的实时写入；刷新/重开会话后从文件恢复，正在核对的进度不丢。
- 确认后 `status: confirmed` 并绑定 revision。**确认后再改图源（无论卡片还是对话）→ 确认失效**，受影响的下游（outline/deck 中引用该图的内容）提示需复核，由 agent 重算关联；已引用旧版本的段落标「来源已变更」，不静默改写。
- 重识别候选不直接写草稿，agent/用户应用后入文件；应用动作的 diff 聊天可见。

## 8. 相对 SmartJC 的简化清单

| SmartJC 原版 | v1 处理 |
|---|---|
| 三栏工作台（目录/画布/证据栏） | 右侧栏工作台单栏连续列表 + 聊天轻卡片（摘要与入口） |
| 八手柄 + 键盘微调 | 四角手柄；键盘微调可选 |
| 跨页图块、图号归属转移、原位改号弹确认 | 不做；跨页图整页/主块 + 疑点，归属问题走对话候选 |
| 全局 Undo/Redo 树 | Figure 级「恢复自动结果」+ 操作即时写文件 |
| Panel↔图注片段手动关联调整 | 自动关联 + 疑点标注；手动调整走对话（agent 直接改 json，diff 可见） |
| AI 只读问答（禁止自然语言改框） | agent 直接编辑草稿文件，diff 聊天可见；与人工调整冲突先说明（skill 软约定） |
| 按发现/按原文组织视图 | 仅按 Figure 组织 |
| 编辑用 working copy + 显式保存事务 | 文件即草稿，确认时定稿 |

## 9. 边界情况

- **无 Panel 的单图**：整图直接可用，允许直接采纳，不强制细分。
- **双文件**：统一核对流，Figure 块与网格标注文件角色（主论文/补充材料）与各自页码；图注按来源文档定位。
- **重叠框**：非错误；仅疑似串入邻图主数据时提示。
- **扫描件/加密/损坏 PDF**：解析阶段拦截并提示更换，不进入图源核对（沿用 SmartJC）。
