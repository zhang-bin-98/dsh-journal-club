# 图源核对细化设计（v1）

> 实施状态：移动/四角缩放、增删 Panel、标签编辑、图注高亮、放大编辑、页图裁切预览与 RPC 写入已实现；本次真实页面验收以 [架构 §7](../architecture/架构设计.md#7-分阶段实施计划) 为准。以下交互规格仍作为验收要求，未执行的页面行为不视为已验证。
>
> 隶属 [产品设计](产品设计.md) 4.3 步骤的交互细化。参考 SmartJC `docs/ui/图源核对.md` 的完整规格，按 dsh「聊天卡片 + 右侧栏 + 文件即真相」形态裁剪。

## 1. 流程位置与入口

- 前置：论文分析完成（全文解析 + 自动切分已产出候选框）。
- agent 完成分析后，在聊天流发出**图源卡片**（进度摘要 + 只读缩略图一览 +「打开核对工作台」/「确认图源」按钮）并停在等待状态；右侧栏 JC tab 切入核对工作台模式，步骤条第 2 步显示「等待核对」。不自动推进。
- 主论文与补充材料（如有）共用一次核对与一次整体确认，分组标识文件角色与页码。

## 2. 界面分工：右侧栏为工作台，聊天卡片为轻量入口

框编辑是长时间、精细、需要稳定画布的工作，放固定的右侧栏工作台；聊天卡片会被后续消息推挤且画布受限，只承载流程时刻与入口。对话联动不受影响——agent 修改 figures.json 后工作台自动刷新并高亮变更框（文件即真相）。

| | 聊天·图源卡片（轻） | 右侧栏·JC 工作台（重） |
|---|---|---|
| 定位 | 流程时刻 + 入口 | 核对主工作区，从 figures.json 实时驱动 |
| 内容 | 进度摘要（N Figure · M Panel · 疑点 K）、只读缩略图一览、「打开核对工作台」按钮、「确认图源」快捷按钮 | Figure 连续列表与全部框操作（见 §3–§5）、单图放大编辑、固定底部整体确认 |
| 生命周期 | 随聊天流逝 | 核对期间常驻；agent 对话修改后自动刷新并高亮变更框 |

「确认图源」在卡片与工作台双入口：无需手动调整的用户看一眼摘要直接在卡片确认，零跳转。

## 3. 工作台：Figure 连续核对列表

工作台主体为 Figure 顺序列表（含补充材料图，不按论文图号强制排序），支持「全部图 / 未查看 / 有疑点」筛选和逐图折叠；已排除图默认折叠。筛选仅改变浏览范围，不改变图源或整体确认范围。项目进度与产物入口默认收在顶部详情中，可手动收起工作台查看其他阶段。每个 Figure 一块：

```text
▾ Figure 3 · 未查看 · ⚠ 疑点 1                         [放大编辑]
[A] [B] [C ⚠] …（单行横向滚动） [＋ 添加 Panel] [标记已查看] [更多操作]
来源文件 · 页码 [适应页面 / 150% / 200%]  │ 当前 Panel C
[页面渲染 + 框叠加，可滚动]              │ 标签 [C] [删除 Panel]
                                        │ [裁切预览，随栏宽等比放大]
                                        │ [打开正式裁切]（已有资产时）
                                        │ 疑点说明 · 关联图注片段
                                        │ ▸ 完整图注
```

- 列表在右侧栏面板内连续滚动（同 dsh Files tab 模式），不受聊天流推挤。编辑器按自身容器宽度响应：达到 700 CSS px 时使用左画布、右预览与属性两栏；更窄时为单栏、小预览，保留「放大编辑」入口。宽布局的画布和右侧证据区域有高度约束，右侧标签/删除在预览上方且不随长图注滚出；证据区只有一层滚动，不为图注另设滚动容器。Panel 标签单行横向滚动，添加按钮不随导航横滑；整条 Figure 工具栏随当前图纵向滚动，不吸顶、不覆盖画布；标记已查看直接显示，排除与两项 AI 操作收入有文字的「更多操作」。筛选、摘要和刷新合并在工作台头部，整体确认仍固定在底部。
- 「放大编辑」使用浏览器原生模态对话框并复用上述响应式布局；内联和放大均提供适应页面 / 150% / 200% 缩放（倍率相对适应页面尺寸）和滚动画布。保持 PDF pt 坐标映射，关闭后回到原列表位置；编辑组件不随放大切换卸载，保留标签草稿和操作开始版本。原生模态负责焦点约束，Escape 先取消添加模式，再关闭弹窗。单图弹窗只负责编辑，不新增整体确认或保存事务。
- **栏宽调整**：宽布局在画布和属性间提供可拖动分隔条，默认约 60:40；原图比例偏好可在 30%–75% 间调整，同时保证两栏最小宽度。分隔条支持左右方向键、Home/End 到边界、双击恢复默认。比例只保存在当前编辑组件内，放大/关闭时保留，不写图源文件、不新增持久化配置。窄布局隐藏分隔条。宽布局的预览随栏宽等比增长，不再受固定 160px 高度限制；长图在证据区滚动，标签/删除仍在上方。窄布局继续使用限高小预览。
- **坐标基准**：host 从原始 PDF 返回旋转后的真实页宽高，client 按显示宽高将 PDF pt 映射到页面，不用 Figure 外接范围猜整页尺寸；支持 150/300 DPI 页图及非标准纸张。
- **图源粒度**：原文每个有标签的 Panel 保留独立身份，同一标签内的多坐标轴保持完整；汇报中的合并展示使用 compose_panels，不把多个字母 Panel 合成一个图源身份。无子图的单图、用户明确要求的整图，以及必要标注无法矩形分离时的整图兜底可使用 whole-Panel（见 §4）。
- **框叠加**：Panel 框以彩色边框 + 标签角标叠加在页面渲染图上；自动切分标疑点的框（重叠、疑似串入邻图、无标签、边缘穿切密集内容）显示 ⚠️ 角标，悬停显示理由。未解决的裁切或关联问题必须同时写入 figures.json 对应 Panel 的 flags 和核对说明，不能只在文字报告中告知而让卡片显示“疑点 0”。
- **状态呈现**：Figure 头部、Panel 标签和画布角标均标出疑点；选中使用强调色，疑点使用警告色和文字。全部疑点逐项翻译展示，图注待复核不遮盖其他问题。
- **裁切预览**：选中框的预览严格按选区裁切、等比显示，不露选区外内容；显示取自已有页图，正式资产仍按同一 pt bbox 从原始 PDF 重渲染，不能把压缩预览当成交付裁切。工作台改框后立即重裁该 Panel（见 §4），使 agent 读取的 `figures/<id>.png` 与工作台所见一致。agent 最后一次改框后、展示核对卡片前，须对全部变更 ID（包括 whole-Panel）调用 crop 并检查实际资产；asset 路径存在不代表图片已同步。候选框必须保全原始标签、坐标轴、图例和统计信息；解析框可能漏掉这些外围内容，应对照原页外扩。必要时允许框重叠并标注串入内容，不能为了边缘干净而截掉科学信息。
- **图注**：当前 Panel 的裁切预览、标签、疑点及关联图注片段集中展示；完整图注仍可折叠查看；选中 Panel 时高亮其对应片段（多对多，如 "b–c" 同一片段高亮 b、c）；公共说明只标适用的 Panel，不无差别复制。
- **跨页图注**：断句或后部 Panel 缺少关联时，agent 必须核对相邻页（含页底）的 `page_footnote`、普通文本与原 PDF；`image_caption` 和 Markdown 可能未带续文。核实后接回断句并更新 `caption_refs`，`caption.page` 保持起始物理页，完整页码范围写入分析底稿。只消除已解决的图注疑点并纠正旧的截断误判；跨页图注补全不等于新增跨页图像拼接功能。

## 4. 单 Figure 框操作集

| 操作 | 交互 | 说明 |
|---|---|---|
| 选中 | 点框或点标签 chip | 同步高亮裁切预览与图注片段 |
| 移动框 | 拖动框体 | 仅动当前 Panel；以原始 PDF 页面为边界，若超出初始 Figure region，同次 CAS patch 将 region 外扩至包含新框，不移动其他 Panel |
| 调整大小 | 四角手柄拖拽 | 简化自原版八手柄，热区 12px；同样允许外扩 region，包含校验保持不变；方向键微调为可选实现 |
| 删除 Panel | 选中后 Delete / 按钮确认 | 移除该 Panel 身份及关联，不动其他框 |
| 添加 Panel | 「＋ 添加 Panel」进入框选模式，拖出框后原位填标签 | 允许空标签，不按位置猜 A/B/C |
| 改标签 | 选中 Panel 后编辑标签；失焦或 Enter 提交，Escape 取消 | 新增 Panel 后聚焦标签输入；标签修改保留旧图注关联并标「关联待复核」 |
| 排除本图 | 按钮，需确认 | 弃图语义：不用于汇报，身份与图注保留，覆盖校验按用户主动弃图处理 |
| 标记已查看 | 按钮 | 标记该 Figure 核对完成（导航状态，非逐图审核门槛） |

操作即时经 host `JournalClubService` 调用 `update_figures` 写入 `figures.json`（草稿态，见 §7；乐观锁防 UI 与 agent 并发覆盖，冲突时提示重载），无独立保存按钮。移动框、调整大小、添加 Panel 与补图保存成功后，再经同一 host 调用 crop 重裁这些 Panel：新登记的 asset 推进 revision，已有 asset 只换像素；改标签、删除、排除与标记已查看不触发重裁。重裁失败时框仍保留并在该图内提示「裁切未刷新」，确认图源时的全量重裁兜底。标签输入、拖框及删除/排除确认使用开始操作时的 revision；写入依次排队，前一次未完成时后一次等待而不丢弃，并跨过本端刚完成且不改 Panel 下标的写入（标签、状态、框、追加、重裁），外部修改与删除仍按冲突处理（D36）。文件监听不能静默替换未提交标签，也不应清空同页图像使编辑视图跳动（含补图页）；读取 figures.json 临时失败时重试一次，仍失败保留上次内容并提示，内容损坏才清空。冲突就地显示在发起操作的 Figure 中；折叠不隐藏报错，筛选隐藏该图时顶部兜底，放大弹窗内同样可见，保留标签输入供用户检查后显式重试。「恢复自动结果」发送限定 Figure 的对话请求，由 agent 查找滚动快照并恢复，不另建草稿存储或候选审批门。

**科学规则继承**：不抹白、不擦除、不重绘科研像素制造分隔；共享图例允许框适度重叠（重叠不报错，疑似串入邻图主数据才提示）。逐边区分本图截断与邻图串入，只外扩缺失自身内容的边，能安全收紧的边应收紧，不能轮轮整体外扩。矩形难以独立保留必要标注（坐标/图例/比例尺/统计）时保留整图并标疑点，不强行产出残缺子图：保留原字母 Panel 身份和疑点，额外登记 `label: null` 的整图参考 Panel 供汇报引用；说明采用兜底的原因，不将它计作成功的独立切分。若异样痕迹在原 PDF 的独立渲染中同样存在，记为源文件限制，不以抹除方式伪装修复。

## 5. 添加 Figure、重识别与对话修正

**添加 Figure（漏检兜底）**：右侧栏/卡片提供「漏了一张图？」入口 → 选择来源文件与页码（清空或输入无效页码时保留上一页预览并禁用保存，合法新页加载时清除旧框） → 页面缩略图上拖出整图范围 → 填图号（可空）→ 创建新 Figure 并自动补做 Panel 与图注关联，失败保留人工框并给局部重试。**v1 不做跨页图块追加**：跨页 Figure 自动按主块或整页处理并标疑点，用户可调框，不拼接多页（SmartJC 的跨页图块/图号归属转移不移植）。

**重新识别（单 Figure）**：按钮标明「让 AI」，发送期间禁用重复请求，发送完成显示去聊天查看的提示；恢复自动结果同样处理。按钮发送限定 Figure 的对话请求；agent 视觉重看高清页图与图注，在说明与人工调整的冲突后经 `update_figures` 直接更新，聊天 diff 与工作台高亮供用户监督，不增加应用候选的确认步骤。

**对话修正（与 SmartJC 的分歧点）**：SmartJC 规定图源步骤 AI 严格只读、禁止自然语言改框。dsh 形态下 agent 是用户信任的操作主体（与其编辑代码文件同等地位），对话修正如「Figure 4B 应该包含下面那排」由 agent 经 `update_figures` 修改草稿，编辑 diff 在聊天流天然可见——这就是监督机制，不自建候选确认门。skill 层面的行为约定（软约束，非硬门）：改动与用户已手动调整的框冲突时先说明再动；大范围操作（整篇重识别、全部重排标签）先讲计划。误操作恢复走对话让 agent 改回或从 update_figures 滚动快照恢复，不建 Undo 树。

## 6. 确认模型

- 沿用 SmartJC「连续浏览 + 一次整体确认」：浏览状态（未查看/已查看/已调整/有疑点/已排除）只是导航信息，**不设逐 Figure 勾选审核**。
- 卡片尾部与工作台固定底栏均有主按钮「**确认图源，生成大纲**」。
- 点击时若有未查看 Figure 或未处理疑点，**提示但不阻断**（「还有 2 个 Figure 未查看、1 个疑点未处理，确认将按当前状态继续」）——尊重用户主动省略。
- 人工检查、调框与整图兜底属于正常使用流程。模型首轮不完美、细微邻图边缘或超出两轮，不单独阻止确认；优先解决影响理解的缺图、关键内容截断与错误引用，其余疑点如实保留，避免反复微调。验收口径见 [D28](../decisions.md#d28-按人机协作场景验收模型输出2026-10-30)。
- 确认动作：对全部未排除的 Panel 按当前框从 PDF **重新裁切**落盘（不用预览压缩图；兜底工作台未刷新的重裁）→ 读取裁切后的 revision 写入确认记录（裁切登记新 asset 会推进 revision，必须在其后读取）→ 触发 outline.md 生成 → 进入确认点 2。

## 7. 数据与版本

- `figures.json` 全程是唯一真相：草稿态（`status: draft`）接受工作台与 agent 经 `update_figures` 的实时写入（写入通道带乐观锁与滚动快照）；刷新/重开会话后从文件恢复，正在核对的进度不丢。
- 确认后 `status: confirmed` 并绑定 revision。**确认后再改图源（无论卡片还是对话）→ 确认失效**，受影响的下游（outline/deck 中引用该图的内容）提示需复核，由 agent 重算关联；已引用旧版本的段落标「来源已变更」，不静默改写。
- 重识别和对话修正直接经统一写入通道落盘；用户可从 diff 检查，需回退时按 `.history` 快照恢复相关内容。

## 9. 边界情况

- **无 Panel 的单图**：整图直接可用，允许直接采纳，不强制细分；数据上归一化为唯一一个空标签 whole-Panel（bbox = 整图范围），裁切与 deck 引用与普通 Panel 无异。
- **双文件**：统一核对流，Figure 块与网格标注文件角色（主论文/补充材料）与各自页码；图注按来源文档定位。
- **重叠框**：非错误；仅疑似串入邻图主数据时提示。
- **扫描件/加密/损坏 PDF**：解析阶段拦截并提示更换，不进入图源核对（沿用 SmartJC）。
