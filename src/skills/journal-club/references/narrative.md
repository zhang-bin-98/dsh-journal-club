# 科研讲述与分页规则

规则移植自 SmartJC 的 common、extract-evidence、summarize-paper、speech、speech-structure、slides 提示词及 paginateSpeech；已将应用内 Claim/Source/Speech ID 与结构化返回契约改为本项目 markdown、页码和 panel ID。research 策略沿用其证据组织方法，取舍规则按本项目的主图覆盖要求适配。这里规定讲述判断，不引入应用状态或私有数据模型。

## 逐页底稿

完整整理当前页明确陈述的本文发现、方法和证据，不按汇报时长筛选。相邻页只用来消解断句、图注续页和代词，不重复搬运相邻页独立发现。纯参考文献页可以没有发现；正文无图的结果仍需保存。每项发现独立保留物种、样本、实验组、干预、比较方向、终点及遗传背景，不能依赖上一条补条件。

区分本文直接实验、作者解释和前人工作。讨论中的带文献编号观察即使没写 previous work，也不能冒充本文实验。图源描述只是定位辅助，不是得出结果或显著性的依据。回查原文与图注核对数字、单位、比较方向和否定关系；认定原文冲突前，放大核对对应原页，排除底稿抄录或识读错误。如原文确有冲突，分别保留来源并标注，不自行统一，也不凭加总矛盾反推哪一个原文数字必错。

统计量必须保留所属模型、分析单位和比较条件，不能用某个相关模型的 R² 概括全研究效应大小，也不能把关联对象占比当成方差解释率。不同分析的阈值和证据等级分别保留。群体平均趋势不代表每个个体同向；未显著不代表无效应；前后时点分别显著与否不等于效应差异显著；与政策或暴露变化同期不证明因果。标题、要点和讲稿使用同一证据强度，不能只在末尾加免责声明。

模型模拟的虚拟患者结果须在结论中明确限定，不能写成已观察到的临床获益；仅在复发者中计算的复发时间不能替代全队列无进展生存终点。比例之差区分百分点与相对变化。批评也须有证据：未说明独立验证不等于已证明复用了校准数据，未展示可观测方案不等于已证明临床不可实施。

作者明确提出的未知机制、替代解释、测量限制和未来工作逐项保存；不以泛泛“尚需研究”覆盖具体未知。汇总时以主论文首页确定论文身份，综合相同结论但保留不能合并的条件、方向和不确定性。汇总不删除逐页底稿，也不把尚未读到的内容认定为全文缺失。

## 组织完整讲述

图源核对后，从底稿组织问题、必要设计、发现、综合限制和结论。每个发现讲清：为什么做、实验对照是什么、观察到什么、哪张图支持、能得出什么及不能得出什么。来源可跨段复用，一段可关联多个 panel，必须实际支持措辞而非仅在同页邻近。

推荐学术结构：论文身份（可核实的题名、作者、期刊与年份）→ 必要背景与知识缺口 → 研究问题或假设 → 总体研究设计 → 按科学问题组织的结果证据 → 综合解释与贡献 → 局限、替代解释 → 主要结论与讨论问题 → 按需备份。各部分可合并或跨页，不规定固定页数、比例或每项独立成页，也不按每个 Figure/Panel 各开一章。总体设计交代队列/模型、比较组、实验或分析单位与核心流程；具体方法随相关结果就近说明，避免集中铺陈试剂和操作步骤。主线最后回答整体研究问题，而非停在孤立观察；区分作者结论与汇报者的评价，不编造机制模型来补全故事。

## 主图覆盖与讲稿控时

- **主图全部进入正式汇报正文**：按论文编号、图注和所在章节区分正文主图与 Supplementary / Extended Data，不按 PDF 文件名判断。除用户明确指定的取舍外，正文主图及其所有有标号 Panel 都应在备份页之前清晰出现。可整图展示，或拆页/拼图累计覆盖；不以只放 A 代表整张 Figure，不把主图仅放进备份或缩成不可辨认的缩略图。示意图、阴性结果和关键对照同样保留；无需重复展示整图及其全部子图。
- **补图按证据作用安排**：直接影响核心结论强度的补充证据进入主线；扩展方法与其他补充证据可放备份，完整发现仍留在底稿。研究策略中的“取舍”指文字详略与补充材料安排，不授权删减正文主图。
- **尊重明确取舍与缺口**：用户明确排除或手工删除的图不自动恢复，记录具体例外；仅有 excluded 状态而无明确取舍依据时，核对并报告差异，不将模型遗漏解释为用户授权。缺失或损坏的主图如实报告，不能编造资产或宣称全覆盖。沿用已有人工核对和确认点，不增设逐图审批。
- **时长通过讲稿调节**：先压缩宽泛背景、常规技术科普、重复过渡和数字逐项朗读，按证据作用分配详讲/简讲。详讲说明实验问题、模型/对照、关键读图、结论边界与过渡；简讲仍点明图号或 Panel 范围、比较、结果及其在证据链中的作用，不能只写“略过”。同一实验的并行 Panel 可合并讲述，不给每张图平均分配字数，不因简讲省掉会改变解释的条件或负结果。
- **诚实估时**：在结果页或科学单元的讲稿开头，用普通文字给出“讲述提示（不口播）：详讲/简讲，约……”，配一份实际可讲的讲稿；不另造长短两份内容源。按语言、术语、图密度、读图停顿和转场估算粗略区间，核对主线总时长；备份与问答另计，用户未说明问答是否包含时明确估时口径。不把固定字速、固定每页秒数或提高语速当成达标依据。压缩后仍超时，保留完整主图与压缩讲稿，在既有确认点报告预计区间及差距，让用户决定延长时长或明确取舍，不偷偷删图或虚报耗时。
- **覆盖自查**：outline.md 末尾用简短 Markdown 表记录“正文 Figure/Panel 范围 → 计划章节/证据单元 → 详略与粗略预算 → 已明确例外/缺口”；此时不固定页码。slides 确认前对照原文主图清单、实际图像（组合图须展开 groups.members）与发现底稿，在确认回复中给出“正文 Figure/Panel → 实际正文页”及遗漏说明。备份页不抵充正文覆盖，整图覆盖按真实像素检查，不能只凭文件名。最终页码核对不回写已确认的大纲，不额外创建覆盖数据文件；validate 的结构检查不能替代这项语义与视觉自查。

讲述提示属于演讲者备注，完整保留在讲稿和导出的 notes 中，不排入投影正文，也不计入口播字数。合并简讲只合并讲述，不合并或重命名图源 Panel 身份；同页组合沿用 compose_panels 与成员记录，既有整图回退仍按实际内容核对覆盖。

## 按研究类型组织证据

选择最贴切的一种研究策略：

- [机制研究](research/mechanistic.md)：干预、功能与机制验证。
- [组学研究](research/omics.md)：高通量、计算发现及验证。
- [临床研究](research/clinical.md)：人群、比较组与临床终点。
- [转化与混合研究](research/translational.md)：人体与模型等多类证据。
- [通用研究](research/general.md)：方法工具或无法归入单一类型。

策略是组织建议；用户语言和重点要求优先，不能因此改变实验事实或证据强度。

## 分页与科学图像

从已确认 outline 的完整讲述分页，保持发现、条件、顺序和证据关联；不在分页时自由改写成另一套科学故事。按完整句意、结论与图组密度分界，不机械一段一页，不为固定页数丢讲稿。长段只在完整句子边界拆分；SmartJC 的 300 字检查、约 240 字分块可作提醒，不作为强制页长。页内讲稿合起来应完整承接大纲讲述，没有遗漏或重复分配。

每页围绕一个主要信息；结果页标题是克制、准确的结论，设计、背景与讨论页可用研究问题或主题标题，不强行写成发现。正文提供简短解释而非复述标题，长解释进入可见讲稿。保留专业命名、来源和原始 Figure/Panel 编号，避免营销式形容词、夸张比喻与无证据的“突破”。学术感来自证据和推理，不来自堆字、装饰图或大量章节封面。

图页以可读原图为中心，通常放少量可独立阅读的 Panel；过密则拆页，不为固定页数删图。避免同一页堆叠整图及其子图造成重复；必要的整图定位与后续放大可分开呈现。跨 Figure 证据可组合，但每个成员须有明确来源，优先保留原 Figure 的内部布局。轴、组别、图例、统计信息与比例尺完整优先。无图页使用准确短文字，不编造图源；不拿通用配图代替实验结果。

首次拼图先看原始页图，参考作者的行列分组、组别/对照配对、相对大小与阅读顺序，不默认改成统一网格。主图拆页时尽量按原图的实验或比较单元拆分，保持同组对照邻近；属于同一比较的共享图例、坐标或统计标注不能拆丢。原排列过密时可为可读性调整，但保持证据关系并简述原因；用户指定和已有手动布局优先，不自动还原成原文布局。

既有讲述语言保持一致，保留专业实体、原图文字和准确单位。富集不等于过表达，μM 不等于 μm，轨迹推断不等于真实时间，基因表达不等于蛋白功能。用户要求强化措辞也不能超过证据。

## 局部修改

显式页码和 Figure/Panel 标识优先；只修改请求必需的内容，保留稳定 ID、来源和科学限定。缺少证据时按需读相关底稿，不因局部编辑重跑全文。图源变化走 update_figures，正文维护原 markdown；修改后复核受影响引用和确认有效性。不要把 SmartJC 的候选提案/应用审批流程带入本插件。
